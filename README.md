# นิทานมังกร — ฝึกอ่านภาษาไทย

Thai reading stories for Pordee. Eight dragon friends from seven tribes set out to collect the seven colored stones and stop the Dark Queen. Season 2 begins with an egg from a forgotten eighth tribe in the deep sea.

**Read online:** https://1492w.github.io/dragon-story/

## Files

| File | What it is |
|---|---|
| `index.html` | Reader — chapters 1–60, Mali/Sarabun font toggle, text size, quick-jump buttons for the latest five chapters |
| `นิทานมังกร_ตอน_๑-๖๐_print.pdf` | Black-and-white print edition (Mali font), one chapter per page start |
| `ฝึกคัดลายมือ_นิทานมังกร.pdf` | 23-page handwriting practice worksheet using words from the story, grouped by theme, vowel, and vowel reduction |

## Story so far

- **ภาค ๑ (ตอน ๑–๕๕):** ฟ้า and friends gather the seven stones and seal ราชินีมืด
- **ภาค ๒ (ตอน ๕๖–):** a year later, the sea turns strange and ฟ้า finds น้องแสง, a dragon from the lost deep-sea tribe
